# MekaStore Downloader

تطبيق تحميل وتثبيت MekaStore تلقائياً لنظام Windows.

## التحميل المباشر

- **Windows (.exe):** [MekaStore-Downloader.exe](https://github.com/mekaapp/mekastore-downloader-exe/raw/main/MekaStore-Downloader.exe)

أو عبر موقعنا الرسمي:
- https://admin.mekastore.com/download

## كيف يعمل

1. حمّل `MekaStore-Downloader.exe`
2. افتح الملف (لا يحتاج تثبيت — Portable)
3. سيقوم البرنامج تلقائياً بتحميل آخر إصدار من MekaStore وتشغيل المثبّت

## الدعم
